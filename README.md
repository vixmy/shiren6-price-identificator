# シレン6 値段識別ツール

「風来のシレン6 とぐろ島探検録」のお店の値段から未識別アイテムを絞り込むツールです。
値段を入力すると、その買値・売値に一致するアイテムが即座に表示されます。

- 使う: https://vixmy.github.io/shiren6-price-identificator/
- 値段データの出典:
  - [値段一覧表 - 風来のシレン6 とぐろ島探検録 Wiki](https://shiren6.game-info.wiki/d/%c3%cd%c3%ca%b0%ec%cd%f7%c9%bd)
  - [武器 - 同 Wiki](https://shiren6.game-info.wiki/d/%c9%f0%b4%ef) / [盾 - 同 Wiki](https://shiren6.game-info.wiki/d/%bd%e2)
  - 武器・盾の修正値による値段の計算式: https://note.com/shiny_llama970/n/n8469520feb5f
